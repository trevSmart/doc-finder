# Documents d'exemple

Aquesta carpeta conté documents d'exemple per provar la funcionalitat de DocFinder.

## Tipus de documents suportats

- PDF (.pdf)
- Documents de Word (.doc, .docx)
- Arxius de text (.txt, .md)
- Documents RTF (.rtf)
- Documents OpenDocument (.odt)

## Com afegir documents

1. Copia els teus documents a aquesta carpeta
2. Actualitza la pàgina de documents
3. Els documents apareixeran automàticament a la quadrícula

## Configuració

Pots modificar la configuració editant el fitxer `config.json` a l'arrel del projecte.
